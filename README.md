# Бесплатные оповещения о TikTok LIVE на iPhone

Мониторинг: [@alena_polevaya](https://www.tiktok.com/@alena_polevaya) и [@myza.muza](https://www.tiktok.com/@myza.muza). Уведомления приходят в Telegram.

## Настройка (один раз)

1. Создайте Telegram-бота: откройте **@BotFather** в Telegram, отправьте `/newbot`, придумайте имя, сохраните выданный **bot token**. Никому его не пересылайте.
2. Перейдите в чат с созданным ботом и нажмите **Start** (или отправьте `/start`).
3. Чтобы узнать **chat ID**, откройте в браузере `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`, заменив `ВАШ_ТОКЕН` своим токеном. Найдите в ответе `"chat":{"id":...}` и скопируйте число `id`. Если список пуст, отправьте боту сообщение и обновите страницу. **Не публикуйте URL с токеном**.
4. На [github.com](https://github.com) создайте **публичный** репозиторий, например `tiktok-live-alert`. Для публичных репозиториев стандартные GitHub Actions бесплатны. Файлы проекта будут видны всем, поэтому никогда не загружайте в него токен Telegram.
5. Загрузите в корень репозитория `monitor.py`, `requirements.txt`, `state.json`, а файл `check-live.yml` — строго в папку `.github/workflows/`. При загрузке через сайт GitHub удобно сначала распаковать ZIP на компьютере и сохранить структуру вложенных папок. Можно также через **Add file → Create new file** ввести путь `.github/workflows/check-live.yml` и вставить его содержимое.
6. В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret**. Создайте два секрета:
   - `TELEGRAM_BOT_TOKEN`: токен из BotFather.
   - `TELEGRAM_CHAT_ID`: числовой идентификатор чата.
7. Откройте **Actions → TikTok LIVE notifications → Run workflow**, отметьте `test_notification` и запустите. В Telegram должно прийти тестовое сообщение.
8. После этого проверки будут запускаться автоматически по расписанию примерно каждые 5 минут. Задержки возможны. Telegram на iPhone должен иметь разрешение на уведомления.

## Важно знать

- Определение LIVE основано на **неофициальной** библиотеке `TikTokLive`. TikTok может изменить механизм работы, заблокировать автоматический запрос или ограничить доступ. Поэтому гарантировать обнаружение каждого эфира невозможно.
- Если эфир завершится между проверками, программа его пропустит. Планировщик GitHub иногда срабатывает позже расписания.
- Оповещение приходит **один раз при переходе offline → LIVE**. Если проверка не удалась, прежнее состояние сохраняется. Однако если блогер завершит один эфир и начнёт новый между двумя проверками, второй может не быть распознан как новый.
- Новые публичные репозитории могут требовать включить Actions в настройках. В публичном репозитории без активности расписание может быть отключено GitHub после 60 дней; коммиты состояния считаются активностью, но если изменений нет длительно, проверьте, что workflow не остановился.
- На iPhone не нужны отдельные приложения, кроме Telegram. Уведомления настраиваются в **Настройки iOS → Уведомления → Telegram**.
- **Не загружайте токен или персональные данные в файлы репозитория и не передавайте их другим людям.**
- При проблеме с `TikTokLive` откройте **Actions → последний запуск → Check lives** и проверьте журнал ошибок.

## Технология

Python 3.12, TikTokLive (`client.is_live()`), Telegram Bot API, GitHub Actions. В `state.json` сохраняется последний известный статус; обновляется автоматически ботом GitHub Actions.
